## Acceptance criteria

- **Sync tables (PRD §5.2):** `022` = `metric_subscriptions` (ReplacingMergeTree on `updated_at`), `023` = `metric_daily` (MergeTree, TTL 7 days `WHERE is_final = 0`), DDL exactly as the PRD. `exposures` carries `max_session_idx SimpleAggregateFunction(max, UInt16)` (no `visit_number_first`).

- One statement per file (migrate runner limitation), idempotent (`IF NOT EXISTS` / `IF EXISTS`).
- All §5.2 columns on `events` and `events_buffer`; `idx_exp` bloom index on `events` only.
- TTL: page_view in_experiment=0 → 1 day, =1 → 90 days, rest 13 months.
- `exposures` + `mv_exposures` + `event_items` as specified.
- `bun run migrate` on a fresh docker ClickHouse applies 001–023 cleanly, and re-running is a no-op.

- Remember migration 012's lesson: a Buffer table doesn't inherit columns added later.
- `mv_sessions_daily` and `mv_experiment_summary` stay.
