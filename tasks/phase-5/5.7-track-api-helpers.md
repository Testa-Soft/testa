Give clients one way to send PRD-006 events from every surface.

## Acceptance criteria

- Pixel `_testa.track` + helpers `trackAddToCart`, `trackBeginCheckout`, `trackShippingInfo` (add_shipping_info), `trackPaymentInfo` (add_payment_info, with `payment_type`), `trackPurchase` (object form; the existing positional signature still works), `trackLead`, `trackSignUp`, all queue-safe before load.
- Helpers compute `value_native` = Σ price×qty − discount (excl. tax and shipping) when not given.
- `@testa-soft/next` exports `track` + the same helpers; it stamps `exp` from the packed cookie and posts to the edge `/track`; the client provider fires `experiment_view` on `variation_applied`.
- `trackPaymentInfo` requires `payment_type`; `trackPurchase` accepts `coupon` and `payment_type`.
- `pushEvent` keeps working (goal matching).
