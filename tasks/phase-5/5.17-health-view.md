## Goal

Serve the Data health tab and the Summary tracking card as the `view: "health"` query. Implement the `ViewRunner` from 5.18 and replace the stub in `health/view.ts`.

## Acceptance criteria

- Per event: status ok | warning | missing, `last_event_at`, events and visitors per variation, required-param coverage from `EVENT_PARAM_SPEC` (incl. `items[].*`); warning below 95% present.
- Metric availability (full / limited / unavailable + reason) from event presence and param coverage, using the daily metric keys.
- SRM χ² vs configured weights (`ok = p ≥ 0.001`); use P3's `srmChiSquare` if merged, else a local copy + a request for P6 to dedupe.
- `summary` counts.
