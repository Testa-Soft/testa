## Goal

Crobot sums the daily rows for whatever date range a user picks and asks this endpoint for significance. Stateless: no ClickHouse, no Redis.

## Acceptance criteria

- `POST /api/v1/stats` behind the service token. Body: `{ control, confidence?, draws?, metrics: [{ key, model: 'beta' | 'normal', direction?: 'higher' | 'lower', variations: [{ variation, n, x? , sum?, sumSq? }] }], segment?: boolean }`.
- Response: per metric, per variation `VariationStats` (PRD §4.3); control gets `chance_to_be_best` only; `insufficient_data` per §5.1 minimums.
- `segment: true` → 10k draws; else 100k. Max 50 metrics × 10 variations per call (400 `too_large`).
- Seeded per PRD §5.5 so identical input gives identical output.
- p95 under 300 ms for 20 metrics × 3 variations.

## Tests

- F3 golden through the endpoint: chance to beat 0.907 ± 0.005, best 0.876 ± 0.005.
- Same body twice → byte-identical response; validation errors.
