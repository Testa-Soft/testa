## Goal

Capture pre-exposure attribution and device fields so the dimensions are right.

## Context

Part of PRD-006 (`docs/prds/006-ecommerce-events-and-metric-modeling.md`). **Part 5 of the PRD wins over earlier sections when they disagree.** Defaults in §5.1 are decided; don't re-ask.

## Acceptance criteria

- On the first page of a browsing session, store entry referrer, URL, all 5 UTMs and `click_id_type` (gclid, gbraid, wbraid, fbclid, msclkid, ttclid, li_fat_id; type only, never the value) in sessionStorage; stamp them on `experiment_view` only.
- `readUtms` also reads `utm_term` / `utm_content`.
- `_testa_vn` cookie (max-age 400 d) incremented when a new `_testa_sid` session starts; sent as `visit_number`. Informational only; new vs returning uses `sessionIdx` (PRD §1.3a).
- `screen_w` / `screen_h` on every event.
- Everything is wrapped in try/catch: blocked storage must never break tracking.

## Tests

- Landing page with UTMs, exposure on page 3 → `experiment_view` carries the entry UTMs.
- Click-id value never appears in the payload.
