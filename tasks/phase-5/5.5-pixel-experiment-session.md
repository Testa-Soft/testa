## Goal

The pixel owns attribution: sessions slide on every event, events outside a session aren't sent, and every event carries `exp`.

## Context

Part of PRD-006 (`docs/prds/006-ecommerce-events-and-metric-modeling.md`). **Part 5 of the PRD wins over earlier sections when they disagree.** Defaults in §5.1 are decided; don't re-ask.

## Acceptance criteria

- Packed cookie gets a 5th field, `sessionStart`, and a 6th, `sessionIdx`; 4- and 5-field segments still parse (`sessionStart=0` / `sessionIdx=1` if a session is active).
- `sessionIdx` +1 each time a new experiment session starts (PRD §1.3a).
- Sending any event sets `sessionExp = now+3600` for each active experiment; the in-memory copy is authoritative, and cookie writes are throttled to ≤1 per 30 s plus on `pagehide`.
- Every event gets `exp` = active `[expId, varId, sessionStart, sessionIdx]`.
- Events other than `experiment_view` / `_pixel_health` are dropped with no active session and counted in `_pixel_health.props.dropped_no_session`.
- Re-init (PRD §6.1) on **any** page load / SPA navigation for an assigned, still-active experiment with an expired session: new `sessionStart`; `experiment_view` re-fired with the stored variation **only if the page matches**.
- `in_experiment` = `exp.length > 0`.
- Everything above applies only to experiments with `platform_version: "v2"` (absent = v1). v1 experiments keep the legacy path untouched, and a v1-only project behaves exactly as today (regression test).

## Implementation notes

- Middleware in `@testa-soft/next` uses the same codec, so keep it backward compatible.
- Coordinate with pending task 3.16 (page_view emission): page_view still fires at the end of `runExperimentCycle`.

## Tests

- Fake timers: 59 min idle keeps the session alive, 61 min idle expires it, 70 min of continuous activity stays in.
- Two experiments, only one active → `exp` has one tuple.
- A returning visitor after 2 days → same variation, new sessionStart, `sessionIdx` 2, `experiment_view` fired; events in that session carry idx 2.
- Old 4-field cookie parses.
