## Goal

Validate and enrich PRD-006 events at the edge.

## Context

Part of PRD-006 (`docs/prds/006-ecommerce-events-and-metric-modeling.md`). **Part 5 of the PRD wins over earlier sections when they disagree.** Defaults in §5.1 are decided; don't re-ask.

## Acceptance criteria

- Zod: items (≤50, truncate and set `_items_truncated=1`), `item_id` required ≤128 chars, price ≥0, quantity int 1–9999; `purchase_type=upsell` requires `parent_order_id`; `exp` tuples of 3 non-negative ints.
- `checkout_start` → `begin_checkout`.
- `items_count` derived from items when missing.
- `os_name`/`os_version`/`browser_name`/`browser_version` filled; legacy `os`/`browser` unchanged.
- `referrer_domain` from `entry_referrer` (host, `www.` stripped, `(direct)` when empty or same-site).
- `channel` via the 11-rule table, first match wins, rules versioned (`CHANNEL_RULES_VERSION`).

## Implementation notes

- Search and social domain lists live in `channel.ts` as constants.

## Tests

- One test per channel rule row, plus edge cases (gclid + utm email → Paid Search).
- Zod accept/reject table.
