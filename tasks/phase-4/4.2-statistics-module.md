## Goal

Pure statistics used by the AOV and RPV endpoints: a **Welch's t-test** (unequal
variances) for AOV deltas and a **bootstrap** for RPV confidence intervals +
significance. Both are pure functions over numeric inputs — no ClickHouse, no
HTTP — so they're exhaustively unit-testable against known reference values.

## Context

The read-path diagram calls out "Welch's t-test or bootstrap CI" inside the
collector. `metric-summary.ts` defines the output shapes: `AovMetric` carries
`ci_low`/`ci_high`; `SignificanceResult` carries `p_value`/`is_significant`/
`delta`/`delta_relative`. AOV is a per-order mean (Welch on order values); RPV
is revenue/visitor where most visitors contribute 0, so the distribution is
zero-inflated and a bootstrap is more honest than a normal approximation.

## Acceptance criteria

- `welchTTest({ meanA, varA, nA, meanB, varB, nB })` → `{ t, df, pValue }` using
  the Welch–Satterthwaite df and a t-distribution CDF. Two-tailed p-value.
- `aovConfidenceInterval(mean, variance, n, level = 0.95)` → `{ low, high }`.
- `bootstrapRpv(perVisitorRevenue: number[], opts)` → `{ point, ciLow, ciHigh }`
  and `bootstrapSignificance(refSamples, cmpSamples, opts)` →
  `{ delta, deltaRelative, pValue, isSignificant }`.
- **Determinism:** the bootstrap takes a seeded PRNG (inject the seed) so tests
  are reproducible and `Math.random()` is never called (matches the repo's
  no-`Math.random` stance for reproducible pipelines).
- `is_significant` uses `p < 0.05` by default; threshold is a parameter.

## Implementation notes

- t-distribution CDF: implement via the regularized incomplete beta function
  (`betacf` continued fraction) — a standard ~40-line numeric routine. Cite the
  source (Numerical Recipes `betai`) in a comment.
- Bootstrap: resample-with-replacement `B` times (default 2_000), compute the
  statistic per resample, take percentiles for the CI; for significance,
  bootstrap the delta distribution and derive a two-sided p-value.
- Seeded PRNG: a small `mulberry32`/`xorshift` is fine; inject via `opts.seed`.
- Keep each file < 200 LOC; `welch.ts` and `bootstrap.ts` are independent.

## Tests

- Welch: pin `t`, `df`, `pValue` against a known worked example (e.g. from a
  stats textbook / scipy `ttest_ind(equal_var=False)`), tolerance 1e-6.
- CI: symmetric normal input → interval brackets the mean; wider `n` → tighter.
- Bootstrap: fixed seed → stable CI across runs; identical ref/cmp samples →
  `delta ~ 0`, not significant; well-separated samples → significant.

## Out of scope

- Sequential-testing / always-valid p-values (mSPRT etc.) — v1 uses fixed-horizon
  tests; flag in the endpoint response if we later add peeking correction.
- Multiple-comparison correction across >2 variations (note it as a limitation).
