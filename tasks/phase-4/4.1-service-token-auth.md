## Goal

Wire the service-token authentication middleware that guards all `GET /api/v1/metrics/*` routes, and register the route skeleton so the HTTP server knows about Phase 4 handlers before they are implemented.

## Context

The collector's read API is described in `docs/architecture/02-collector.md § Read API` and `docs/reference/api-endpoints.md`. Every `/api/v1/metrics/*` request must carry `X-Service-Token: <SERVICE_TOKEN>` (an env var, already in `config.ts`). The actual per-metric handlers ship in tasks 4.2–4.5; this task just builds the gate and the route-registration layer.

## Acceptance criteria

- `apps/collector/src/auth/service-token.ts` exports a Hono middleware `serviceTokenAuth` that:
  - Returns `401 { error: "unauthorized" }` when `X-Service-Token` header is missing.
  - Returns `401 { error: "unauthorized" }` when the token does not match `config.serviceToken` (constant-time compare).
  - Calls `next()` when the token matches.
- `apps/collector/src/metrics/index.ts` exports a `metricsRoutes` Hono instance with four routes (`/aov`, `/rpv`, `/sessions`, `/funnel`) all returning `501 { error: "not implemented" }`, all protected by `serviceTokenAuth`.
- `apps/collector/src/index.ts` mounts `metricsRoutes` at `/api/v1/metrics`.
- Auth middleware unit tests cover: missing token → 401, wrong token → 401, correct token → 200 (from a stub downstream).
- `pnpm -r typecheck && pnpm -r test && pnpm lint` all pass.

## Implementation notes

### `auth/service-token.ts`

Use `timingSafeEqual` from `node:crypto` to prevent timing attacks on the token comparison:

```ts
import { timingSafeEqual } from 'node:crypto';
import type { MiddlewareHandler } from 'hono';
import { config } from '../config.ts';

export const serviceTokenAuth: MiddlewareHandler = async (c, next) => {
  const token = c.req.header('x-service-token');
  if (!token) return c.json({ error: 'unauthorized' }, 401);

  const expected = Buffer.from(config.serviceToken, 'utf8');
  const provided = Buffer.from(token, 'utf8');
  const match =
    expected.length === provided.length &&
    timingSafeEqual(expected, provided);

  if (!match) return c.json({ error: 'unauthorized' }, 401);
  await next();
};
```

### `metrics/index.ts`

```ts
import { Hono } from 'hono';
import { serviceTokenAuth } from '../auth/service-token.ts';

export const metricsRoutes = new Hono();
metricsRoutes.use('*', serviceTokenAuth);

metricsRoutes.get('/aov',      (c) => c.json({ error: 'not implemented' }, 501));
metricsRoutes.get('/rpv',      (c) => c.json({ error: 'not implemented' }, 501));
metricsRoutes.get('/sessions', (c) => c.json({ error: 'not implemented' }, 501));
metricsRoutes.get('/funnel',   (c) => c.json({ error: 'not implemented' }, 501));
```

### `index.ts` mount

Replace the existing `app.get('/api/v1/metrics/:metric', ...)` 501 stub with:

```ts
import { metricsRoutes } from './metrics/index.ts';
app.route('/api/v1/metrics', metricsRoutes);
```

## Tests

`apps/collector/src/auth/__tests__/service-token.test.ts`:

```ts
import { describe, expect, it } from 'bun:test';
import { Hono } from 'hono';
import { serviceTokenAuth } from '../service-token.ts';

function buildApp(): Hono {
  const app = new Hono();
  app.use('/protected', serviceTokenAuth);
  app.get('/protected', (c) => c.json({ ok: true }));
  return app;
}

const CORRECT = process.env.SERVICE_TOKEN ?? 'dev-service-token-change-me-1234';

describe('serviceTokenAuth', () => {
  it('returns 401 when X-Service-Token is missing', async () => {
    const res = await buildApp().fetch(new Request('http://test.local/protected'));
    expect(res.status).toBe(401);
  });

  it('returns 401 when token is wrong', async () => {
    const res = await buildApp().fetch(
      new Request('http://test.local/protected', {
        headers: { 'x-service-token': 'wrong-token' },
      }),
    );
    expect(res.status).toBe(401);
  });

  it('passes through when token is correct', async () => {
    const res = await buildApp().fetch(
      new Request('http://test.local/protected', {
        headers: { 'x-service-token': CORRECT },
      }),
    );
    expect(res.status).toBe(200);
    expect(await res.json()).toEqual({ ok: true });
  });
});
```

## Out of scope

- Rate limiting, IP allow-listing, JWT. The service token is an internal secret shared with crobot — network-level isolation is the primary protection in production.
- The per-metric query implementations (tasks 4.2–4.5).
