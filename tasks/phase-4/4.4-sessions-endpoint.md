## Goal

Implement `GET /api/v1/metrics/sessions` — returns session-level engagement metrics per variation: total sessions, bounce rate, and pages per session. No FX conversion; no statistical significance (session counts are not revenue metrics). The response matches `SessionsSummary` from `packages/shared-types`.

## Context

Data lives in `mv_sessions_daily` (migration 006, `AggregatingMergeTree`). The MV stores:
- `uniqExactState(session_id)` → merge with `uniqExactMerge` at query time
- `uniqExactStateIf(session_id, event_name = 'page_view')` → sessions that had at least one page_view
- `countStateIf(event_name = 'page_view')` → total page_view count

Bounce rate = `1 - sessions_with_pageview / sessions`. Pages/session = `page_views / sessions`.

## Acceptance criteria

- `GET /api/v1/metrics/sessions?experiment_id=42&from=...&to=...` returns `SessionsSummary`.
- Uses `mv_sessions_daily` with `AggregatingMergeTree` merge functions (`uniqExactMerge`, `countMerge`).
- `bounce_rate` is clamped to `[0, 1]` (guarded against division by zero).
- `pages_per_session` is clamped to `≥ 0` (guarded against division by zero).
- `sample_size` = total sessions for that variation.
- No `significance` field (not applicable for session engagement).
- No `report_currency` param (pure counts).
- `experiment_id` required; returns 400 when missing.
- Default date range: last 30 days.
- Handler tests stub CH and assert response shape, bounce rate formula, and zero-guard.
- `pnpm -r typecheck && pnpm -r test && pnpm lint` pass.

## Implementation notes

### CH query

```sql
SELECT
    variation_id,
    uniqExactMerge(sessions)              AS sessions,
    uniqExactMerge(sessions_with_pageview) AS sessions_with_pageview,
    countMerge(page_views)               AS page_views
FROM mv_sessions_daily
WHERE project_id = {project_id:UInt64}
  AND experiment_id = {experiment_id:UInt64}
  AND day BETWEEN {from:Date} AND {to:Date}
GROUP BY variation_id
ORDER BY variation_id
```

### Response shaping

```ts
const variations: SessionsMetric[] = rows.map(r => ({
  variation_id: r.variation_id,
  sessions: r.sessions,
  bounce_rate: r.sessions > 0
    ? Math.max(0, Math.min(1, 1 - r.sessions_with_pageview / r.sessions))
    : 0,
  pages_per_session: r.sessions > 0
    ? Math.max(0, r.page_views / r.sessions)
    : 0,
  sample_size: r.sessions,
}));
```

### Route wiring

Replace the `501` stub for `/sessions` in `metrics/index.ts`:

